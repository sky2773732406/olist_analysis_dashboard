# Olist 电商销售与用户复购分析报告

> 数据源：Brazilian E-Commerce Public Dataset by Olist（Kaggle）
> 分析工具：Excel、MySQL 8.0、Power BI
> 数据范围：2016-09 ~ 2018-10（趋势分析以 2017 起为准）
> 仪表板截图见 [images/dashboard.png](../images/dashboard.png)

---

## 1. 概述

本项目基于 Olist 巴西电商平台约 10 万笔订单，用 **Excel 清洗、MySQL 分析、Power BI 可视化**三套工具，完成了从数据清洗到交互式仪表板的完整数据分析流程，围绕**销售趋势、品类贡献、地区表现、用户复购、配送体验、支付方式**六个问题展开。

## 2. 数据与口径

- **分析对象**：`order_status = 'delivered'`（已送达）订单。
- **GMV** = Σ(商品金额 `price` + 运费 `freight_value`)。
- **客单价 AOV** = GMV ÷ 已送达订单数。
- **复购** = 同一 `customer_unique_id` 的已送达订单数 ≥ 2。

| 指标 | 数值 |
| --- | --- |
| 总 GMV | R$ 15,419,773.75 |
| 已送达订单数 | 96,478 |
| 商品明细行数 | 110,197 |
| 客单价 AOV | R$ 159.83 |
| 下单客户数（唯一） | 93,358 |
| 平均配送天数 | ≈ 12.6 天 |

## 3. 分析结论

### 3.1 销售趋势

- GMV 整体**明显上升**：从 2017-01 的 R$12.7 万增长到 2018 年月均 R$100 万以上。
- **2017-11 为峰值**（"黑五"大促），GMV 达 **R$1,153,364.20**，环比 **+53.55%**；次月回落 **-26.90%**，2018-01 反弹 **+27.85%**。
- 2018 年稳定在 R$98 万 ~ R$113 万/月，进入平台成熟期。

### 3.2 品类贡献与帕累托

- **Top10 品类合计贡献 62.38% 的 GMV**，符合帕累托法则。
- 品类集中度高：**18 个品类**（共 74 个）即覆盖 **80%** 的 GMV。
- 头部品类：`health_beauty`（9.16%）、`watches_gifts`（8.20%）、`bed_bath_table`（7.95%）。

### 3.3 地区表现

- **SP（圣保罗州）销售最高**，GMV R$5,769,703.15，占全网 **37.42%**。
- 前三名 SP + RJ + MG 合计占 **62.55%**，销售高度集中于东南部经济带。

### 3.4 用户复购与 RFM

- **复购率约 3%**：93,358 名客户中仅 **2,801 人**下单 ≥ 2 次（3.00%）。
- 客户结构极度"一次性"：**97.0%（90,557 人）只下过 1 单**。
- RFM 分层显示高消费客户（M=5）约 1.8 万人，是需重点维护的高价值人群。
- 复购率低说明平台以**拉新驱动**为主，存量复购运营有较大提升空间。

### 3.5 配送体验与评分

- **配送天数越长，评分越低**：相关系数 **-0.334**。
- 配送 ≤5 天平均评分 **4.44**；配送 >30 天骤降至 **2.20**。
- 整体平均评分 **4.086**，差评率（1~2 星）**14.69%**；**延迟送达订单的差评率高达 53.99%**，准时率约 **91.89%**。配送时效是口碑的关键环节。

### 3.6 支付方式

- **信用卡绝对主导**：金额占比 **78.34%**（R$12,542,084.19）。
- `boleto`（巴西本地银行票据）**17.92%**，`voucher` 2.37%，`debit_card` 1.36%。

---

## 4. 结论与建议

1. **销售增长强劲但集中**：GMV 持续增长、大促达峰，但品类（Top10 占 62%）、地区（SP 占 37%）高度集中。建议头部持续深耕，同时**培育腰部品类**以降低集中度风险。
2. **复购是最大短板**：3% 的复购率意味着几乎全靠拉新。建议搭建**会员/召回体系**，针对 RFM 高价值人群做复购激励。
3. **配送时效决定口碑**：配送天数与评分显著负相关，延迟单差评率过半。建议**优化物流、设超时预警**，压缩长尾配送时长。
4. **支付以信用卡为主**：占比近八成，可围绕信用卡场景做**分期/优惠**活动。
